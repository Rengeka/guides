# Creating first linux kernel module

Clone latest linux kernel repository (requires ~5.0 GB of free space):

    git clone git://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git

Create ```hello_sample``` directory in ```linux/samples```

Add ```hello_module.c``` and ```Makefile``` to ```linux/samples/hello_sample```

Add this code to ```hello_module.c```:
```c
#include <linux/module.h>
#include <linux/kernel.h>

int init_module() {                    
    printk(KERN_INFO "Hello, World!\n");
    return 0;
}

void cleanup_module() {
    printk(KERN_INFO "Goodbye, World!\n");
    return 0;
}

MODULE_LICENSE("GPL");
```

Add this line to Makefile:
```Makefile 
obj-m += hello_module.o
```

Run ```make -C $KDIR M=$PWD modules``` to compile module

    Replace $KDIR with the path to the root of the Linux kernel source (e.g. ../linux if you're in samples/hello_sample)

Run ```make -C $KDIR M=$PWD clean``` to delete all temporary files

Run ```insmod hello_module.ko``` to init module 

Run ```dmesg | tail -n 20``` to see logs

If your logs contain ```Hello, World!```, congratulations! You have successfully created your first linux kernel module!
